# vael-ui changelog (for agents)

What changed in each release, newest first. Read this when upgrading an app, or when code written for an older version behaves differently. For the current API, the component and composable references are the source of truth.

## 0.5.0

### Upgrading from 0.4

Three changes break code: the `motionCss` rename, `beforeClose`, and the list events. The rest change DOM or styles that your CSS and tests may rely on.

- **`motionCss` is now `motion` (breaking).** Everywhere: components, `ConfigProvider`, and the options of `useCollapse`, `useSortable` and `useSortableGroup`. `:motion="false"` still turns the built-in animation off. Find and replace `motion-css` and `motionCss` with `motion`.
- **`beforeClose` is a guard (breaking).** It decides whether an overlay closes and no longer runs your exit. Return `true` to close, `false` to stay open, or a promise of either. The `(done) => …` form is gone, and you no longer call `cancelClose()` after a refusal: the next close asks again.

  ```ts
  // Before
  beforeClose: (done) => {
    if (!dirty.value) return done()
    confirmAction({ title: 'Discard changes?' }).result.then((ok) => {
      if (ok) done()
      else dialogRef.value?.cancelClose()
    })
  }
  // After
  beforeClose: () => !dirty.value || confirmAction({ title: 'Discard changes?' }).result

  // An exit animation moves to a `leave` hook
  // Before
  beforeClose: (done) => gsap.to(panel, { opacity: 0, onComplete: done })
  // After
  motion: { leave: ({ panel }) => gsap.to(panel, { opacity: 0 }) }
  ```

- **List events are gone (breaking).** `chip-enter` / `chip-leave` (Select, Combobox), `item-enter` / `item-leave` (CommandPalette, FileUpload, Timeline), `card-enter` / `card-leave` (Toaster), `row-enter` / `row-leave` (DataTable) and `action-enter` / `action-leave` (SpeedDial) no longer fire. Pass `enter` / `leave` hooks in `motion`. Each gets the item by name (`{ toast }`, `{ row }`, `{ item }`, `{ action }`, `{ chip }`) and waits for the animation you return, with no `done()`. Chips go under `motion.chips`, CommandPalette rows under `motion.items`. Timeline's hooks get the step's `marker`, `connector`, `previousConnector`, `content` and `opposite`; the `TimelineItemParts` type is removed.
- **`force-mount` keeps content mounted**, for its state. It no longer means "I'll animate it": vael-ui leaves force-mounted content's motion to you, through `motion` values or hooks.
- **`motion="false"` covers the panel too** on Select, Combobox, CascadeSelect, DatePicker, TreeSelect and CommandPalette.
- **Message** no longer shrinks while `beforeClose` decides; it leaves once the guard allows it.
- **Button (breaking if you color buttons).** The box is a `::before` layer and the contents sit in `.ui-button-inner`. A `background` or `border` on the button paints under the layer and disappears. Set `--ui-button-bg` / `--ui-button-border` instead; a dashed border is `.my-button::before { border-style: dashed }`. Read a button's color from `::before`.
- **Sortable.** The root is a `div.ui-sortable` with the `<ul>` inside as `.ui-sortable-list`. Your class and scoped styles now reach the root.
- **Tooltip, TooltipHost.** The label sits in `.ui-tooltip-content`, and `.ui-tooltip-panel::before` draws the box. `data-traveling` and `data-morphing` replace `data-sizing-locked`.
- **Hover backgrounds in lists.** Rows in Select, Combobox, CommandPalette, Menu, Tree, TreeSelect, MenuList, DataTable, Pagination, Tabs, SelectButton, Toolbar and Calendar no longer paint their own hover or focus background; one `.ui-indicator` slides behind them. Replace a rule such as `.ui-menu-item:hover { background: … }` with `--ui-indicator-bg`. DataTable's striped and selected rows are see-through tints.
- **`--ui-indicator-bg`** is no longer set on `:root`; it falls back to `var(--ui-muted)`. If your CSS reads it, add that fallback.
- **Stepper.** A step you can't reach yet is a disabled button instead of a `div`.
- **Highlight elements.** Components expose the hover highlight as `highlightEl`; `indicatorEl` stays the name for a selection indicator.

### The motion system

One `motion` prop on every component, one engine behind every animation. See the [Motion guide](./motion.md).

- `motion`: `false`, or an object with values per part (`initial`, `exit`), timing (`spring`, or `duration` + `easing`), `states`, and `enter` / `leave` hooks. Each component exports its type (`DialogMotion`, `SelectMotion`, `ToasterMotion`, …).
- Hooks return what GSAP, motion's `animate()` or `element.animate()` returns, or a promise; the component waits for it, stops it when interrupted and aborts `signal`. Under reduced motion hooks don't run unless `reducedMotion: 'run'`.
- Lists: `stagger`, `leaving: 'pop' | 'hold'`, `appear`, `initial` / `exit` as functions of `{ index, count }`.
- Overlays: `morph: 'trigger'` (or `{ from, hide }`), `linked`, inner parts (`title`, `body`, `footer`) in `initial`, `exitOrder: 'reverse'`, `resize`, `swap`, `surface` (Popover), `targets` with `after` and `steps`.
- Entrances on any component (`initial`, `stagger`, `replay`, `appear: false`), states on every component (keyframes, `times`, `repeat`, repeated parts one at a time, `unchecked` on toggles), indicators with `spring`, `move`, `stretch` and `squash`.
- `v-animate`: `initial` / `exit`, `.size`, `layout`, `layoutId`, `replay`, `when: 'visible'`, `animate`, `progress`, presets, `v-animate:name`.
- `ConfigProvider` `motion`: `{ spring }` for one spring app-wide, or a `MotionStyle` (`version: 1`) by role (`overlay`, `list`, `reveal`, `press`, `content`) or component, with `presets` and an `engine`. `parseMotionStyle` validates a style from JSON.
- `useMotion` for your own components; `await settled()` in tests; `v-animate` entrances render as CSS on the server; the Nuxt module registers `v-animate`.
- Built-in motion stays under 300 ms (drawers and grow-from-trigger aside), eases out both ways, closes faster than it opens, and keeps fades without movement under reduced motion. Drawers close in 350 ms. Popover, Menu and Tooltip grow from their trigger's center.

### New components and features

- **New components:** `Editable` (inline rename), `AnimatedNumber` (rolling digits, `Intl.NumberFormat` options), `AnimatedText` (text swap with width easing), `ColorPicker`.
- **Input** `animated` and `#display` slot (also Textarea, PasswordInput, Combobox, InputNumber); **InputNumber** `animated` and `scrub`; **Button** `hold` (press and hold to confirm, `holdProgress`, `--ui-hold-progress`) and `loader-type`; **Switch** draggable thumb.
- **Progress** segments, `type="circle"` rings, `sweep` gauges, `value-text`; **Loader** `type` (`ring`, `dots`, `bars`, `comet`, `dither`), or your own component; `ConfigProvider` `loader-type`.
- **ConfigProvider** `indicator` (`'glide'`, `'instant'` or a spring) and `haptics`; **`useHaptic`**; **`useColorScheme`** `setMode(mode, { from })` circular reveal.
- **`v-hover-indicator`** gives your own list the sliding hover highlight in one attribute (`.over` for rows with a solid background); **`useHoverIndicator`** is the composable behind it; **`useTabIndicator`** `scroller`, `matchCross`, `maxGlide`, `motion`, `position: 'translate'`, `update()`.
- **`ui` keys for chevrons, clear buttons and icons** across Select, TreeSelect, CascadeSelect, Combobox, Input, AccordionItem, SplitButton, Menu, MenuList, CommandPalette, Breadcrumb, DatePicker, DataTable, Tree, SpeedDial, PullToRefresh and PasswordInput; **Select, TreeSelect, CascadeSelect** `#start` and `#end` slots.
- **Dialog** `origin="trigger"`; **Toaster** `container`; **OtpInput** `variant="field"`, `placeholder`, gliding `ringEl`; **CommandPalette** `#footer` and `activeItem`; **SplitButton** `unified`; **Tree / TreeSelect** `scroll-fade`; **Slider, Knob, Dial** `change` on commit; **BottomSheet** settable `activeSnap`; **useNumberFormat** `formatOptions`; **useListbox** `point(index)`; **Sortable** `restrict-to-list` and a reworked `preview-mode="clone"`.
- **Tokens:** `--ui-duration-drawer-exit`, `--ui-duration-stagger`, `--ui-duration-indicator`, `--ui-duration-indicator-wide`, `--ui-ease-indicator`, `--ui-indicator-bg`, `--ui-duration-number`, `--ui-ease-number`, `--ui-duration-text`, `--ui-ease-text`.
- **`panel-width`** on Select, Combobox, TreeSelect, CascadeSelect, DatePicker and Menu: `'trigger'` follows the field, or a width in px or any CSS length. CascadeSelect's first level is the field's width up to 16rem by default.
- **v-draggable / `useSortable`** reorder a wrapping grid in reading order, slot by slot; a card leaving a grid no longer takes a column away, and a list a card left reorders its own cards again.
- Many fixes: pressed controls keep their full hit area, springs stay stable at 30 fps, right-to-left indicators and Switch, safe areas, phone keyboards, and the full `vael-ui/style.css` now includes every component.

## Earlier releases

Entries before 0.5.0 describe the 0.4 animation hand-off (`motionCss`, `beforeClose(done)`, list events), which 0.5.0 replaced.

- `0.4.8`: **Option groups:** `Select` and `Combobox` take `{ label, items }` entries among `items` and render them as real labeled groups, like `<optgroup>`; arrow keys, typing and search work across groups, and a grouped list renders in full (no `virtualize`). `#group-label` gets the group object you passed (your own fields included) and its options still showing; `#item` also gets the option's `group`; style with `ui.group` / `ui.groupLabel`. `CommandPalette` gets `#group-label` and `group` on `#item` too, and its arrow keys now follow the on-screen order when a group is spread through `items`. **CascadeSelect:** `filter` adds a search box; while typing, the levels become one list of matching leaves with their path (`Africa / Ghana`), every word matching anywhere in the path (also `filter-placeholder`, `v-model:query`, `ui.filter`, and `path` on `#item`). **Menu / CascadeSelect:** each level's panel has `data-level` (`[data-level='2']` styles the second menu), and `ui` now reaches every level (it only styled the first). **Select / Combobox / TreeSelect / CascadeSelect** lists ease to their new height while you search (like CommandPalette). **TreeSelect**'s panel grows with folder expands. **Chips** collapse in place as they leave; selected-row tints are see-through, so custom panel backgrounds show through; option lists never scroll sideways. **Toggles:** `ButtonGroup` `v-model` (+ `multiple`, `allow-empty`) with a `value` on each `Button` makes them toggle by themselves with `aria-pressed` set; `Button` `v-model:pressed` makes one Button a toggle; a Button's own `@click` runs first and `event.preventDefault()` stops the toggle. A toggle that's on now looks different from hover. `Toolbar` shows collapsed toggles as check rows in its overflow menu. **Calendar / DatePicker:** `show-year-buttons` adds « » year jumps; new messages `calendar.previousMonth`, `nextMonth`, `previousYear`, `nextYear`, `previousYears`, `nextYears`; with two months, a month picked from the second month's name now lands second (behavior change); RTL arrows point outward; narrow panels and long labels fit. **Combobox:** `revert-on-blur` (`false` for search boxes, so typed text stays on blur). **Sizing:** every component is sized `border-box` on pages without a box-sizing reset (no visible change with Tailwind/normalize). **SSR:** with the `vapor` condition on the server, `'vael-ui'` loads the Vapor server build.

`onOpenChange` option on `openDialog()`/`openPopover()`; `overlayEl` on the `openDialog()` handle and `useDialogRef()`; Stepper `labelEls`. **Dependencies:** `@vueuse/core` 12 to 15 accepted. **DataTable/Tree** load the drag engine only when `reorderableColumns`/`reorderable` is on (DataTable ~16.8 KB gz initial instead of 22; a press made while it loads is held and replayed). **Animation:** Dialog, Drawer, Popover, Tooltip, Select, Combobox, DatePicker, TreeSelect, Menu, SpeedDial and early toasts animate in when already open on first render. **Fixes:** confirmAction can't be dismissed while an async `onConfirm` runs; Select/Combobox/DatePicker/TreeSelect put `id`/`aria-*`/`data-*` on the focusable control; tooltips add to `aria-describedby` instead of replacing it; v-tooltip text updates while open; Escape inside a Dialog closes a tooltip first; changing `side`/`align`/offsets moves an open panel; nested `closeOnHistoryBack` dialogs close one at a time; Escape ending an IME composition doesn't close overlays; Tour Skip/Done run `beforeClose`, arrow keys in a highlighted input stay in the input; toasts arriving while hovered wait; Collapsible honors long `--ui-duration-enter`; DataTable/Tree clean up a drag cut short by unmount; `openDialog()`/`openPopover()` closed in the same tick settle. **Round 2:** DataTable sort/select-all/resize and Tree selection/collapse are many times faster on large data (row animation turns off above 150 rows; `openDialog()`/`openPopover()`/`confirmAction()` from an unmounted opener still settle; dark-mode contrast fixes (dark text on success badges, deeper info badge fill via dark-only `--ui-info-solid`, lighter info text via dark-only `--ui-info-text`; - `0.4.6`: **New on `ConfigProvider`:** `size` (`'sm' | 'md' | 'lg'`) sets the default size of every button, form control and table inside, and `:motion="false"` makes everything inside change instantly (panels still open and close, toasts and list rows still leave).
